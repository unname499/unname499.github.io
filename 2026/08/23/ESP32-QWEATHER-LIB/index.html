ESP32 和风天气获取库

这个库目前为初版，可能会有其他诡异的问题，遇到问题，欢迎来我的仓库提交Issue！

仓库地址：https://github.com/unname499/ESP32_QWEATHER/

其实README已经够详细了，所以我把使用方法复制过来吧

介绍一下Config gc：
所有参数分别是：你的私钥、项目KID和SUB、你的API HOST、你的API KEY、要查询的地址

  • your-private-key：你的 Ed25519 私钥（JWT 认证时必填，API KEY 认证时传空字符串）
  • your-kid：项目 KID（JWT 认证时必填）
  • your-sub：项目 SUB（JWT 认证时必填）
  • your-api-host：你的专属 API 域名，必填
  • your-api-key：你的 API 密钥（API KEY 认证时必填，JWT 认证时传空字符串）
  • your-real-address：查询天气的城市名称，会自动 URL 编码

另外要注意的是：Config gc()中的gc是可以自定义的，只要下面的WeatherNow weatherNow(gc)中的gc改掉就行。
